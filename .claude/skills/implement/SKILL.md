# /implement
1. Inspect repo state, relevant ADRs, impacted modules, and existing tests.
2. Classify risk. For architecture, schema, dependencies, security, signing, or major scope changes stop and request approval.
3. State short plan with acceptance criteria and verification steps; for large work request plan approval.
4. Make minimal focused changes; add tests and update docs where behavior changes.
5. Run scoped verification; optionally delegate review.
6. Report what changed, exact commands/results, caveats, and draft PR link if created.
