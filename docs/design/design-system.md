# Design system — draft

## Principles
Premium, approachable, dark-first style inspired by rich consumer audio software, without copying proprietary interfaces. System / dark / light preference. List and grid modes share interactions.

## Requirements
- Semantic tokens for color, surface, text, border, spacing, typography, radius, motion and focus.
- Keyboard-first: focus visibility, actionable shortcuts, screen reader labels, predictable tab order.
- Handle empty/loading/error/offline/no-device states; no fake active-routing indicators.
- Support narrow desktop windows, Windows scaling and macOS Retina.
- Respect reduced motion and adequate text/control contrast.

## Open design decisions
Typography, brand identity, token values and icon system are TBD; create after reference research and owner approval.
