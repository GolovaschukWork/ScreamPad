# Product vision

**Name:** ScreamPad. **License:** GPL-3.0-only (owner decision, 2026-10-26).

A premium, accessible, local-first desktop soundboard for general audiences on Windows 11 and macOS 14+.

## Committed experience
- Library with searchable list and grid views, profiles/boards as product evolves.
- Import audio from local files, video files, and approved remote URLs.
- Non-destructive waveform trim and fades; original managed assets remain intact.
- Play sounds while mixing live microphone input to user-installed virtual devices for chat apps.
- Tray operation and global shortcuts; dark-first visual direction with system/light/dark modes.
- No account requirement, no app store distribution, no unexpected telemetry.

## Scope boundaries
- No first-party virtual audio drivers in MVP.
- No plugin marketplace, sync service, or cloud accounts in MVP.
- URL provider list and licensing/compliance must be decided before implementation.
