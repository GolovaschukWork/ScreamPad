# Definition of Done

- [ ] Scope and acceptance criteria satisfied without unrelated changes.
- [ ] Required owner approvals acquired for ADR/schema/dependencies/permissions/security/signing changes.
- [ ] Behavior has appropriate automated tests; high-risk DSP and file imports have negative-path tests.
- [ ] Formatting, lint, typecheck, unit tests and relevant builds executed and reported.
- [ ] Code review completed; critical/high findings addressed or explicitly escalated.
- [ ] Accessibility, empty/error/loading states considered for UI changes.
- [ ] User-facing text uses translation keys in both languages and `pnpm i18n:check` passes.
- [ ] Platform-dependent behavior documented as verified or NOT VERIFIED.
- [ ] Docs, ADRs and user-facing changelog updated when applicable.
- [ ] No secrets, temporary data, unexpected telemetry or unsafe permissions.
- [ ] Draft PR includes change summary, test evidence, screenshots if UI and risk notes.
