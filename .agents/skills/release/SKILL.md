---
name: release
description: Prepare a ScreamPad release checklist and evidence only when explicitly requested by the owner; publication requires separate explicit approval.
---

Follow `docs/engineering/release-policy.md` and `definition-of-done.md`. Check version, channel, changelog, clean tree, CI, platform smoke evidence, signing, notarization, updater signatures, license, FFmpeg compliance, SBOM, hashes, provenance, and rollback. Prepare notes and list gaps. Require explicit owner approval before tag, production artifact, updater manifest, or GitHub Release publication. Never expose credentials.
